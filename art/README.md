# 第一批美术素材

生成方式：内置 imagegen。风格基准为用户确认的 `scene/c01-hall-lit.png`。

本批交付24个WebP素材：5场景、1封面、2 NPC立绘、2 NPC裁切头像、2鬼物、12玩家头像。PNG保留为原稿；玩家原稿由工具返回的方形尺寸统一缩放为256×256头像。场景为1536×1024，立绘与封面为1024×1536。

容量上限：场景、封面、鬼物120KB，NPC立绘80KB，所有头像10KB。`manifest-batch-01.json`记录尺寸、容量及SHA-256；`prepare_assets.py`用于重新导出及生成预览。

提示词记录在`prompts/`。灵堂灯灭版最终以灯亮版为编辑参考：熄灯、保持机位与陈设、棺盖窄缝、无字无人物。第一次独立生成的灯灭草稿未采用。

## 验收边界

- 场景与封面预览：`previews/scenes.jpg`，人物预览：`previews/portraits.jpg`。
- 场景未见人物、尸首或脚印；封面标题为“夜不收”。湿脚印图没有脚或人物。
- NPC为黑底，非透明底。头像从对应立绘裁出。
- `ghost/c01-coffin.webp`为含蓄版候选：面部残缺主要由暗部表达，缺一节食指未清楚呈现。要求明确残缺细节的返修被图像工具安全系统以violence拒绝，未将该图标为严格通过。
- 本次仅生成与整理资产，未接入游戏、未执行浏览器功能验收、未发布。
